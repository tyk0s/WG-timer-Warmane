# WG-timer-Warmane

**WG-timer-Warmane** är ett litet World of Warcraft-tillägg (Addon) och en WeakAura som visar status för **Wintergrasp**-kriget på Warmane-servrar (privatserver baserad på WoTLK 3.3.5a). Det hjälper spelare att enkelt hålla koll på när Wintergrasp startar och slutar genom en visuell timer.

## 🔍 Funktioner

- Visar Wintergrasp-status (aktiv / time left)
- Visuell timer tillagd via både addon och WeakAura
- Designad för Warmane-klienten (WoTLK 3.3.5a)
- Ingen extern serverkontakt behövs

## 📌 Förutsättningar

Det här projektet kräver att du spelar **World of Warcraft: Wrath of the Lich King 3.3.5a**-klienten och ansluter till Warmane-servrar (t.ex. Icecrown, Lordaeron, Onyxia, Frostmourne). Standard WoW-miljöer stödjer addon:en utan ändringar.
