# WG-timer-Warmane

**WG-timer-Warmane** is a small World of Warcraft addon and WeakAura that displays the status of the **Wintergrasp** battle on Warmane servers (a private server based on WoTLK 3.3.5a). It helps players easily keep track of when Wintergrasp starts and ends through a visual timer.

## 🔍 Features

- Displays Wintergrasp status (active / time remaining)
- Visual timer provided via both an addon and a WeakAura
- Designed specifically for the Warmane client (WoTLK 3.3.5a)
- No external server communication required

## 📌 Requirements

This project requires **World of Warcraft: Wrath of the Lich King 3.3.5a** and a connection to Warmane servers (e.g. Icecrown, Lordaeron, Onyxia, Frostmourne). Standard WoW environments support the addon without any modifications.
